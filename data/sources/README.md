# Data sources and attribution

Candidate references (not copied wholesale):

| Project | Research area | Reuse requirement |
|---|---|---|
| [MLBB-Hero-Scraper](https://github.com/warungerik/MLBB-Hero-Scraper) | Hero and skill metadata collection | Check exact license and endpoint terms; validate independently |
| [MLBB-API](https://github.com/ervin-sungkono/MLBB-API) | Wiki-backed heroes, equipment and emblems | Review license and preserve required notices |
| [MLBB community repositories](https://github.com/topics/mlbb) | Candidate datasets and tools | Inspect each repository license; topic membership grants no reuse rights |

Every imported/researched record needs provenance:
```json
{"source":"https://example.org","retrieved_at":"2026-11-14T00:00:00Z","game_version":"unknown","confidence":"reported","notes":"What was checked."}
```
A structured third-party API is not automatically authoritative.
